# PyShield SOC – Real-Time Network Monitoring and Threat Analysis System

## Overview
PyShield SOC is a Python-based cybersecurity project designed to monitor network traffic, identify suspicious activities, classify potential threats, and maintain security event logs.

## Features
- Live network packet monitoring using TShark.
- Network scanning using Nmap.
- Rule-based threat classification.
- Security event storage using SQLite.
- Streamlit dashboard for monitoring security events.
- CSV security report generation.

## Technologies Used
- Python
- Nmap
- Wireshark / TShark
- SQLite
- Streamlit
- Pandas

## Project Purpose
To demonstrate practical knowledge of network monitoring, basic threat detection, and security event analysis.

## Disclaimer
This project is an educational cybersecurity prototype and is not a replacement for an enterprise-grade SIEM or IDS.
